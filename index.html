What this prototype is — and isn't, yet

This runs entirely in your browser: entries save locally, nothing touches a server. It's built so you can feel the experience before we commit to real infrastructure.

Accounts, sync, sharingNeeds a real backend and auth.
AI Memory HistorianNeeds a live model connection.
EncryptionA security architecture decision, not a UI toggle.
