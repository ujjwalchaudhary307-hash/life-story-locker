What this build is — and isn't, yet

Auth and every drawer's data now run through Firebase for real — Authentication + Firestore, no browser-only storage left. Nothing here is decorative.

Photos, video, voiceNeeds Firebase Storage + Blaze billing — a cost decision, not made for you.
AI Memory HistorianNeeds a live model connection and an API key.
Legacy unlock-date enforcementCurrently UI-only — a signed-in owner could read their own sealed entry early via devtools.
Rate limiting / App CheckNot yet configured — recommended before real traffic.
Life Story Locker — Firebase-backed. Society entries are public to everyone visiting this site; every other drawer is private to your account.
